Run an AI coding repository inventory in GitHub Actions.

The public AI Agent Repository Hardening Audit Action inventories common Claude Code, Codex, Cursor, MCP, agent-instruction and automation surfaces and writes the result to the job summary.

The audit logic does not execute target repository code, install dependencies, or make network requests. It enumerates file and directory names only; the purpose is to expose configuration sprawl and review gaps before broader agent permissions are granted.

Copy-paste workflow

name: AI agent repository audit

on:
  workflow_dispatch:
  pull_request:

permissions:
  contents: read

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4
        with:
          persist-credentials: false
      - uses: OssaBellator/claude-code-mcp-hardening@v1

What it inventories

  • AGENTS.md, CLAUDE.md, Copilot instructions and common agent command directories;
  • common repository-scoped MCP configuration paths;
  • Claude/Cursor/VS Code agent settings paths;
  • GitHub Actions, Claude hooks and common local automation configuration;
  • secret-like filenames without reading or printing their contents.

What it deliberately does not do

  • run your build, tests, scripts or MCP servers;
  • install dependencies;
  • read repository file contents;
  • claim a vulnerability exists based on a filename;
  • replace a full security review.
