Run a read-only inventory locally

The public repo includes a zero-dependency Node.js audit utility that enumerates configuration file names only. It does not read file contents, execute project commands, or use the network.

git clone https://github.com/OssaBellator/claude-code-mcp-hardening.git
node claude-code-mcp-hardening/audit.mjs /path/to/your/repo

The output is an inventory aid, not a vulnerability verdict or security certification.
