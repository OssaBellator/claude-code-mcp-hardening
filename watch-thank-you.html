This is a one-time purchase, not a recurring subscription. It covers one public GitHub repository and three read-only reports:

  1. Baseline: after the paid intake is detected.
  2. Day 30: a fresh audit appended to the baseline report.
  3. Day 60: a final fresh audit appended to the same report.

Keep the repository public on the report dates. The audits use public GitHub evidence only and do not clone or execute repository code, install dependencies, or require private access.

Do not send secrets. The watch never requires passwords, API keys, recovery phrases, private keys, card details, production customer data, or private-repository access.

If the repository is private or unavailable on a scheduled report date, delivery pauses and retries later rather than treating missing evidence as a clean result.

This is a repository hardening review, not a penetration test, security certification, legal opinion, compliance assessment, or guarantee that all vulnerabilities will be found.
